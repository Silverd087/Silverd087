### What I'm building

**[RAG-Lab](https://github.com/Silverd087/RAG-Lab)** — A full-stack lab for building, comparing, and benchmarking RAG pipelines end to end: chunking, indexing, retrieval, and generation are all configurable, with LLM-as-judge evaluation (DeepEval) and side-by-side pipeline comparison. FastAPI + Celery + Qdrant on the backend, React + TypeScript on the front end, deployed to Kubernetes via GitOps ([RAG-Lab-Infra](https://github.com/Silverd087/RAG-Lab-Infra)) with Argo CD, Kustomize, and Prometheus/Grafana monitoring.

**[InvoFlow](https://github.com/Silverd087/AI-Serverless-Invoice-Processor)** — A serverless SaaS that turns invoices and specs into structured data, using Amazon Textract for OCR and Amazon Bedrock (Claude 3.5) for extraction, on a fully event-driven AWS architecture (Lambda, AppSync, DynamoDB, CloudFront).

**[AWS Rekognition Label Generator](https://github.com/Silverd087/AWS-Rekognition-Label-Generator)** — An event-driven image-labeling pipeline: S3 upload triggers Rekognition object detection, Pillow annotates bounding boxes, and results are indexed in DynamoDB with SNS alerting on failures.

**[EC2 Backup Automation](https://github.com/Silverd087/EC2-Backup-Automation)** — A hands-off EBS snapshot pipeline using Lambda and EventBridge, with tag-based instance selection and a 7-day retention policy to keep storage costs in check.
